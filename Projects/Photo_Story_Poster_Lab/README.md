# Photo Story Poster Lab

Photo Story Poster Lab is an interactive multimedia web application that transforms a user-uploaded image into a stylized poster or visual card.

The application runs fully in the browser and does not require any backend server. It uses HTML, CSS, JavaScript and the HTML Canvas API.

## Main Idea

The goal of the project is to allow users to create a visual story from their own photograph.  
Instead of working as a standard photo editor, the application generates different thematic poster layouts based on the uploaded image.

## Features

- Upload a custom image
- Generate multiple poster styles:
  - Movie Poster
  - Detective Case File
  - Cyberpunk ID
  - Retro Postcard
  - Magazine Cover
  - Wanted Poster
  - Album Cover
  - News Front Page
- Add custom title, subtitle, date/year and extra text
- Change accent/detail color
- Generate a random style
- Add custom movable text elements
- Add stamp-style graphic elements
- Move added elements directly on the canvas
- Edit added text by double-clicking
- Delete selected elements using the Delete key
- Export the final result as PNG, JPEG or WEBP

## Technologies

- HTML5
- CSS3
- JavaScript
- HTML Canvas API
- FileReader API
